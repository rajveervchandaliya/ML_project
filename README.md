🍎 Food Calorie Counter

A simple and beginner-friendly Streamlit web application that allows users to enter a food item and view its approximate calorie count.

✨ Features

Simple and beginner-friendly interface

Food item text input

Displays approximate calorie information

Handles food items that are not available in the database

Built with Python and Streamlit

🛠️ Technologies Used

Python

Streamlit

📁 Project Structure
food-calorie-counter/
│
├── app.py

⚙️ Installation
1. Clone the repository
git clone https://github.com/YOUR_USERNAME/food-calorie-counter.git

2. Open the project folder
cd food-calorie-counter

3. Install the required packages
pip install -r requirements.txt

▶️ Run the Application

Run the following command:

streamlit run app.py


The application will open automatically in your web browser.

🍽️ Example

Enter a food item such as:

Apple


The application will display its approximate calorie count.

⚠️ Note

The calorie values provided by this application are approximate. Actual calorie content can vary depending on portion size, ingredients, preparation method, and other factors.
